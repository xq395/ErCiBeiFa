# 北伐打卡

考研 11408 计划 + 打卡 + 课表 + DeepSeek 学习助手。**手机单机使用为主**，需要时和电脑交换数据。

## 手机上用（单机）

1. 把 `dist/北伐打卡.html` 发到手机（微信/QQ 文件传输），用浏览器打开（Edge / Chrome / Safari 都行，别用微信内置浏览器，它会清数据）。
2. 浏览器菜单 → "添加到主屏幕"，之后从桌面图标打开。
3. 数据全存在这个浏览器里，不联网也能打卡、计时、看课表。DeepSeek 功能需要联网，但不需要电脑。

这个 html 由 `python tools/build.py --with-key` 生成，**里面带着 DeepSeek Key，不要外传、不要上传 GitHub**。`dist/`、`data/` 和签名密钥都在 `.gitignore` 里；要发给别人用 `python tools/build.py`（不带 Key，对方在设置页自己填）。

## 安卓 App 和桌面小组件

### 安装

1. 电脑开着 `启动.bat`，手机浏览器打开控制台里"安卓安装包："那个地址（`http://电脑IP:8765/apk`）下载。也可以把 `dist/北伐打卡.apk` 用微信/QQ 发到手机。
2. 打开 apk 安装。OPPO（ColorOS）会提示"未知来源"或"安全检测"，选 允许 / 继续安装。如果要求登录 OPPO 账号做检测，可以在 设置 → 安全 → 安装外部来源应用 里给文件管理/浏览器开权限。
3. 第一次打开时允许"通知"（计时到点提醒要用）。

### 添加小组件

**推荐**：App 里 课表 页顶部 → "添加到桌面"，系统会弹窗确认。

手动添加：桌面空白处双指捏合 → "插件"或"小组件" → 找"北伐打卡" → 拖"北伐 · 今日课表"到桌面，默认 4×2，可以拉大。
注意 ColorOS 负一屏的"卡片"只收 OPPO 服务卡片，第三方小组件不在那里。

没弹窗：设置 → 应用管理 → 北伐打卡 → 权限，打开"桌面快捷方式"，再点一次。

- 小组件显示：日期和第几周、各科今天分钟/目标、按时间排的课和空闲块（已结束的自动隐藏，正在进行的标 ▶）、每块推荐的下一课时。
- 点标题打开"今天"页，点课程行打开"课表"页，点空闲行打开"今天"页。
- 数据来自 App：每次在 App 里改动，或切出 App 时刷新一次。它在每节课开始/结束的时间点自动刷新，不联网也能用。

### OPPO 上建议的设置

ColorOS 会限制后台，不设置的话小组件可能不按时刷新、计时提醒可能延迟：

- 设置 → 应用 → 应用管理 → 北伐打卡 → 耗电管理：打开"允许后台运行"（或选"不限制"）。
- 同一页 → 通知管理：允许通知，"计时提醒"渠道打开横幅和铃声。
- 安卓 12 以上如果提示"闹钟和提醒"权限，打开它，计时提醒就能准时响。

### App 和网页版的区别

- App 里跑的是同一套页面代码，数据存在 App 自己的存储里。**和浏览器里的单文件版是两份数据**：从浏览器换到 App 时，先在浏览器版 设置 → 导出备份文件，再到 App 里导入。
- App 里"导出"会直接存到手机 `下载/北伐打卡/` 文件夹。
- 计时器到点时，即使 App 在后台或锁屏，也会发通知。
- 返回键：先关弹窗，再回"今天"页，最后退到后台（不会退出计时）。
- 页面代码的更新走 设置 → 更新（从电脑拉、从 GitHub 拉，或导入更新文件），不用重装 App。只有改了 `android/` 里的原生代码才需要重新打包安装。

### 打安卓包

```
python tools/build_apk.py --with-key
```

打包前会先跑 `node tools/smoke.js`：按 index.html 的顺序加载全部脚本，有任何一个加载时报错就停止打包。

需要 JDK 17 以上和 Android SDK 的 `build-tools/35.0.0`、`platforms/android-35`（放在 `%LOCALAPPDATA%\Android\Sdk`，可以从 `https://mirrors.cloud.tencent.com/AndroidSDK/` 下载 `build-tools_r35_windows.zip` 和 `platform-35_r02.zip` 解压）。不用 Gradle 和 Android Studio。

签名密钥在 `data/beifa.keystore`，**不要删**。换了密钥，手机上就不能覆盖安装，只能卸载重装，而卸载会清掉 App 里的数据。

## 更新

电脑上改了 `web/` 里的代码后，手机怎么拿到新版本：

- **连着电脑**：电脑开着 `启动.bat`，手机打开时会自动问一次电脑（10 分钟内最多一次）。有新版本时顶部出现黄条，点它，再点"立即更新"。电脑端每次都从 `web/` 现打包，改完不用重新 build。
- **GitHub**：电脑和手机不在同一个 Wi-Fi 时用这个，手机不连电脑也能更新，见下面"用 GitHub 更新"。
- **离线**：电脑运行 `python tools/build.py`，把 `dist/北伐打卡-更新.json` 发到手机，在 设置 → 更新 → 导入更新文件。

更新只换页面代码，打卡数据、Key、对话都不动。新版本存在手机浏览器里，之后断网也照样用新版本。

出问题的退路：
- 安装前会先检查语法，有语法错误的包不会装。
- 新版本启动时报错，会自动删掉它，退回 html 文件里自带的版本，并提示一句。
- 设置 → 更新 → 退回内置版本，可以手动退回。

`dist/北伐打卡.html` 只在第一次安装时需要。以后发更新文件就行，不用再换 html。

**注意**：v1.32 起管家支持 LaTeX 公式、流式输出和音频播放。流式和音频只需要页面更新；公式的 KaTeX 字体/脚本在 APK 的 `assets/vendor/katex/` 里，页面更新不会带过去，所以数学公式要装一次 **v1.32 以上** 的 APK（覆盖安装不丢数据）。v1.33 起 PDF 按页自动选文字层或识图，这个只改页面代码，`设置 → 更新` 就能拿到。

### 用 GitHub 更新（手机不连电脑）

代码推送到 GitHub 后，Actions 会自动把页面更新包发布到 `update` 分支。手机 设置 → 更新 → "GitHub 更新源"填 `用户名/仓库`，保存，再点"检查 GitHub 更新"。

- 仓库必须是 **Public**：手机通过 `raw.githubusercontent.com` 读 `version.json` / `bundle.json`，私有仓库需要 token，不能直接用。
- 仓库里只有程序：`data/`（打卡数据、Key）、`dist/`（构建产物，可能带 Key）、`*.keystore` 都由 `.gitignore` 排除；Actions 还会跑 `tools/check_secrets.py` 再查一遍。**`dist/北伐打卡.html` 如果是 `--with-key` 生成的，带着 Key，不要上传或发给别人。**
- 首次推送：GitHub 网页新建一个空仓库（Public，别勾"Add a README"），然后在本文件夹里：
  ```
  git remote add origin https://github.com/<用户名>/<仓库名>.git
  git push -u origin main
  ```
- 国内网络如果 `raw.githubusercontent.com` 打不开，GitHub 更新源可以填 jsDelivr 镜像的完整地址：`https://cdn.jsdelivr.net/gh/<用户名>/<仓库>@update`（镜像有缓存，刚推送时可能晚一点才会更新）。
- 成功之后，以后电脑上改完 `web/`，`git add -A`、`git commit`、`git push` 即可；手机下次打开会自动检查（10 分钟内最多一次），也可以手动点更新。
- GitHub 更新只换网页代码。改了 `android/` 里的小组件、通知等原生代码，仍要 `python tools/build_apk.py` 重新打包安装。
- 手机第一次要有"GitHub 更新源"这个功能，得先通过电脑更新一次（或装一版包含它的 APK）；之后才能完全脱离电脑。
- 公开仓库会包含 README、课表和管家提示词里的学校/目标信息；介意的话把仓库设为 Private，继续用电脑或导入文件更新。

## 和电脑交换数据

两种方式都是**合并**，按每条记录的修改时间取新的，不会互相覆盖：

- **文件**：设置 → 导出备份文件，发到另一台设备 → 设置 → 导入备份文件。
- **局域网**：电脑双击 `启动.bat`，手机连同一个 Wi-Fi，设置 → 填电脑地址（控制台"手机："那行）和 PIN → 和电脑合并。电脑端数据存在 `data/data.json`，知识库正文存在 `data/docs/`，每天第一次合并前自动备份 `data.json` 到 `data/backups/`（正文请把 `data` 文件夹一起备份）。校园网隔离设备的话，让电脑连手机热点。换了热点、电脑 IP 变了不用手动改：连不上时 App 会在同一网段里自动找电脑，设置里也有"自动找电脑"按钮（需要 v1.15 及以上的 App）。
- **知识库正文**：目录随普通合并走，正文在合并后自动补齐——手机导入的文档，电脑上会自动多出正文；电脑上已有的，手机打开时也会自动取。正文是切好的文本段，存在电脑的 `data/docs/`，不塞进 `data.json`，也不传原始 PDF/图片文件。

## 电脑上用（从哪进）

双击项目文件夹里的 `启动.bat`。它启动服务后会**自动打开浏览器**（`http://127.0.0.1:8765`）；万一没弹出来，手动在浏览器里输入这个地址，收藏或装成应用即可。服务已经开着时再双击，只会再打开一次页面，不会重复启动。

**不要直接双击 `web/index.html`。** 那是以 `file://` 打开，浏览器把它当成另一个网站，存储完全独立，所以看起来是全新空数据。这个页面顶部会有一条提示，点"打开电脑版"会跳到正确地址。

第一次在某个浏览器打开时，数据不会自动出现（数据存在各自的浏览器里）：

- 电脑上已经有 `data/data.json` 的话，页面顶部会提示"电脑上已经有 N 条打卡记录"，点"和电脑合并"，输入 PIN（电脑控制台里有，和 `data/config.json` 里的 `pin` 相同）就拉下来了。
- 也可以从手机推上来：手机 设置 → 和电脑合并（地址填控制台"手机："那行，PIN 相同）。
- 电脑端的日常数据也存在这个浏览器的 localStorage 里，`data/data.json` 是同步中转和备份。换浏览器、清缓存后重新合并一次就回来了。
- 打卡照片的原图只存在产生它的设备上（照片的文字说明会同步）；知识库正文会按需从电脑取。

## 一天从几点算起

- **打卡记录**（时长、学完的课时、睡前结算、连续天数）凌晨 4 点才切到新的一天：熬夜学到 1 点，记的还是前一天。这段时间"今天"页顶部会提示"凌晨 4 点前记的时长仍算 X 号"。
- **课表和桌面小组件**按日历日期，0 点就切到新的一天。凌晨时小组件下面的分钟统计仍显示正在记的前一天。

## 页面

- **今天**：只放今天要做的。顶部一条输入框可以直接问管家（发出后跳到管家页）；三科各一张卡（目标分钟、已做、下一课时），"开始 40 分钟"计时，"讲义"看这一课时的要点；今天的目标、可选复习（到期课时和卡片）、固定小格、今天的记录；睡前结算 21 点后才展开。
- **管家**：单独一页，整屏对话。快捷按钮：排今天、该复习什么、本周复盘。切到别的页时管家还在后台回复，回完导航上"管家"会亮个点。
- **课表**：今天的课和空闲整块交错排列。每节课给一条"课上做什么"，每个空闲块推荐放哪一课时。下面是周视图，可以翻周。
- **课时**：400 个 40 分钟课时。点星星打星，点标题看讲义。
- **看板**：整体概况。DeepSeek 进度总结；距初试、本阶段剩余、本周小时、连续/累计在线；各科掌握程度（星级分布）；待办概况（到期复习、待复习卡片、进行中目标）；热力图、最近 7 天、各书进度、导出 CSV。
- **目标**、**知识**：见下文。
- **设置**（右上角 ⚙）：DeepSeek Key 和模型、导入导出、电脑地址、开学日期、导入课表、打卡规则。

## 打卡照片、今日长图和表格

- 今天页"打卡照片"卡片（或问答条左边的 📷）可以一次选多张照片：笔记、错题、书页都行。管家会自动识别每张学了什么、属于哪科，写成一句说明；点照片可以改说明，或者"问管家"让它讲题、挑错。
- 照片本身只存在本机，说明文字会随备份和电脑同步，管家查当天记录时能看到。
- **今日长图**：把当天的学习时长、各科进度条、学完的课时（带星级）、学习记录、固定小格、照片和睡前结算画成一张竖图。每张照片左上角有"长图"勾选，只有勾上的才会画进去（默认全选；选几张画几张，竖着排，太多会很长）。可以"保存到相册"（存到 相册 / Pictures / 北伐打卡）或直接"分享"给微信 / QQ。也可以对管家说"生成今天的打卡长图"。
- **表格**：导出当天的 CSV（下载 / 北伐打卡），Excel、WPS 可以直接打开。
- 权限：安卓 10 及以上保存图片走系统的媒体库，不用申请存储权限；只有安卓 8–9 会弹一次存储权限。选照片用的是系统文件选择器，App 也不需要读取相册的权限。

## 管家（首页对话框）

DeepSeek 通过工具调用直接读写你的数据：查进度、查某天记录、给课时打勾/取消（支持"从头到某课时全部打勾"）、补记或删除时长、改结算、改星期系数和每天目标分钟、写备忘、生成讲义。

- 回复是**流式输出**的，边生成边显示；模型先思考时，"思考中…"可以点开看思考过程（DeepSeek 的 reasoning_content），答完在"日志"里还能看到每轮思考、输出、工具调用、耗时和 token。
- 数学公式用 LaTeX 渲染（KaTeX）：行内 `$...$` 或 `\(...\)`，独立成行用 `$$...$$` 或 `\[...\]`。App 和电脑版自带 KaTeX；单独发到手机的 html 没打包字体，需要连着电脑才会加载，否则先显示原始 TeX。
- 输入框是多行的：自动换行、随内容长高；Enter 发送，Shift+Enter 换行。今天页顶部的问答条也一样。
- 管家标题栏的 **"日志"**：本机 AI 调用日志，包含每轮的模型、温度、思考强度、上下文条数、工具名、耗时、token 用量、思考过程、输出、工具结果和错误。可以复制 JSON、清空；最多保留最近 8 轮，只存本机，不参与同步和备份。

- 每条消息下面有操作：
  - **复制**：你的话复制原文；管家的回复复制这一轮的全部文字。
  - **修改**：就地改你说过的话，点"重新发送"后，这条之后的对话会被替换，用上文 + 改过的话重新生成。如果这条之后管家改过数据，会先问你要不要撤销这些改动（推荐撤销，否则会在已改过的数据上再改一次）。
  - **撤销改动**：只出现在管家改过数据的那一轮下面。把数据恢复到这句话之前，对话保留；之后几轮如果也改过数据，会一起恢复。快照存在本机，最多 10 份，关掉 App 也还在。
- 管家调整的目标分钟只影响今天和以后，历史的达标判断不变。说"恢复"就会改回计划默认值。
- 对话记录随备份文件和电脑合并一起同步。
- 工具按话题分组：每轮只带常用工具，加上你最近几句话涉及的组（课表、目标、知识库、复习、记忆、记录和规则）。没带到的，管家会自己调 load_tools 加载。这样每轮少发 2000–3000 tokens。

## 课时星级与复习

课时不再只有"学了 / 没学"，改成 0–5 星：0 未学，1★ 很生，2★ 有点印象，3★ 刚学完，4★ 比较熟，5★ 完全掌握。

- 课时页每行右边有五颗星，点几颗就是几星，再点同一颗清零。计时结束、讲义底部也能直接选星。"今天"页的"学完"按钮记 3 星。旧数据里打过勾的课时都当作 3 星。
- 打星后自动安排复习：1★ 1 天后，2★ 2 天，3★ 4 天，4★ 10 天，5★ 不再提醒。知识库卡片用同一套星级和间隔，卡片每多复习一次间隔再放宽 25%（最多 +75%）。到期的课时在课时页标"该复习"。
- **复习是可选任务**："今天"页的"可选复习"卡片列出到期课时，不做也不影响打卡。点"复习了"重新打星，点"跳过"推迟 2 天。设置里可以关掉提醒，或者调整每天最多显示几条。
- 管家可以打星：说"洛必达刚学完，等价无穷小已经很熟了"，它会分别打 3★ 和 4★。问"今天该复习什么"，它会列出到期课时并说明是可选的；排计划时只提一句，不会每轮都提醒。

## 多个对话

管家标题栏左边是当前对话名，点开能看到对话列表；"＋新"开一个空白的新对话。

- "默认对话"固定在最前面，随时能切回来接着聊。其他对话可以改名、删除；新对话聊几轮后，管家会自己起一个短名字。
- 所有对话共用同一份长期记忆、知识库、打卡数据和对话设置（提示词、参数）。
- 对话列表随备份文件和电脑合并同步。

## 知识库

**支持的文件**：txt、md、各种代码（c/cpp/py/java/js/sql…）、csv/json/yaml/xml、tex、html；pdf（**按页判断**：文字层正常就用文字层，碎片化/公式字体/没有文字层的页自动改用识图，最多 30 页/份）；docx、pptx（按页）、xlsx（按工作表，单元格 Tab 分隔）；图片（识图转文字）；音频（mp3、m4a、aac、wav、ogg、flac…，直接在 App 里播放）。txt 会自动识别 GBK 编码。

**在管家里发文件**：输入框左边的"＋"可以选图片，也可以选上面这些文件，**支持一次选多个**（图片最多 8 张，文件不限）。文件会先存进知识库，消息里只带文件名。管家**只有在你明确提到它时才去读**，比如发了附件并问它、说"看看我那份计组提纲"。读的时候按段读，长文档先看开头，需要再往后读，不会一次塞满上下文。DeepSeek 的接口本身不收 PDF，所以 PDF 是在手机上转成文字后再给它的。

"知识"页，四个分栏：

- 每个分栏顶部都有"＋ 上传文件"和"粘贴文字"。
- **文档**：导入 txt / md / pdf / docx / 图片（图片会自动识图转文字）/ 音频，或者直接粘贴文字。导入后切成小段存在本机，能自动识别 GBK 编码的 txt。PDF 不再要求必须有文字层：每页先看文字层质量，碎片太多、平均行长过短、出现公式字体的私用区字符，或者根本没有文字层，这一页就自动改用识图，页首会标成 `【第 N 页 · 识图】`；正常文字页标 `【第 N 页】`。文档页上方有 **"强制识图"** 开关，公式多的讲义即使文字层看着正常也可以勾上，慢一些、费 token。PDF 解析库（pdf.js，约 1.5 MB）放在 `web/vendor/`，只在第一次导入 PDF 时加载；App 里自带，浏览器版需要连着电脑。
- **音频（英语听力）**：文档页里点音频的"播放"，用内置播放器听，支持 0.75× / 1× / 1.25× / 1.5× 倍速和循环。音频原文件只存在导入它的设备上（元数据会同步，但 Blob 不传），在另一台设备上打开会提示"音频只在导入它的设备上"。管家**听不到音频**，把它发进对话只会显示 🎧 附件，不能转写。
- **检索**：在本机搜文档段落、卡片和长期记忆，不联网、不花 token，关键词高亮。点结果跳到原文位置。"让管家根据这些回答"会把问题交给管家。
- **卡片**：题目或知识点，加上答案和标签。熟悉度分 6 档：不会 / 很生 / 有印象 / 会但慢 / 熟练 / 掌握。顶部条形图显示各档数量。
- **复习**：今天到期的卡片按"最不熟的先来"排序。看完点熟悉度，自动安排下次复习：不会是明天，很生 1 天后，有印象 2 天，会但慢 4 天，熟练 8 天，掌握 16 天；复习次数越多，间隔越长。"今天"页会显示待复习数量。

管家和知识库：
- 回答知识点、讲题前，管家会先检索知识库，并注明出处（文档名）。
- 发错题或说"记一下这题"时，它会存成卡片；说"会了 / 还是不熟"时，它会记录熟悉度。
- 在文档上点"出题"，管家会从这篇文档里挑重点出题，做成卡片。
- **记忆搬家**：卡片页点"把记忆整理进知识库"。管家会把知识性的长期记忆移进知识库，记忆里只留一句"某某是薄弱点"这样关于你本人的短信息，避免长期记忆越来越长。记忆超过 25 条时，它也会主动建议整理。

文档正文（切好的文本段，不是原始 PDF/图片文件）会在和电脑合并后自动补齐：手机导入的，电脑上会自动多出正文；电脑上已有的，手机打开时会自动取。正文按文档 id 存在电脑的 `data/docs/`，不塞进 `data.json`；电脑没开时正文留在原设备，打开文档会提示从电脑取。文档目录、卡片和熟悉度照常同步。设置 → 和电脑合并 里也有单独的"同步知识库正文"按钮。

## 目标

"目标"页（原来的"计划"页，阶段计划还在下面）。大目标有截止日，可以拆成若干小目标，每个小目标是一次能坐下来做完的事（约 20–60 分钟），也有自己的截止日。

- **让管家拆解**：说"12 月 12 日六级考 550 以上，听力阅读弱，每天能挤 40 分钟"，它会建好大目标，拆成带日期、分钟数的小目标，并说明拆法。也可以点"新目标"手动建。
- **状态**：按开始日到截止日线性算"现在应完成几个"，实际少于这个数就标"落后"，过了截止日标"已超期"。小目标全部完成时，大目标自动完成。
- **自动排进时间**：每天按紧迫度挑出该推进的小目标（每个大目标今天要做 剩余数÷剩余天数 个，至少 1 个），装进今天的空闲块。标了"课上碎片"、且不超过 30 分钟的（比如背单词），塞进教务课的课上时间。它们会显示在"今天"页、课表页的空闲块和课上提示，以及桌面小组件里，点"完成"就勾掉。
- 说"某某做完了"，管家会帮你勾；说"这个目标推迟一周"，管家会改截止日。进度总结也会把目标算进去。

## 管家改课表

直接说就行，例如"周六 9-12 点和 14-16 点是英语网课，周日同时间段是数学网课"、"下周三的操作系统停课了"、"周日上午网课改成 9:30 开始"。

- 加的是**自定义日程**，存在 `S.events`，不会改教务课表本身。支持每周重复（可设起止日期）、只有某一天、以及"某天某节课停课"。
- 自定义日程会显示在课表页（带"自定义"标签，可以点"删"）、周视图（蓝色）和桌面小组件里，也会从空闲时段里扣掉。
- 考研科目的网课会关联到该科的下一课时，提示你课后补记时长。
- 每轮对话第一次改数据前存快照，"撤销"能回到改之前。

## 对话设置

管家标题栏的"设置"按钮展开面板：

- **上下文**：列出全部对话记录，亮色的是会发给模型的部分，显示估算 token 数和上一轮实际用量。点任意一条可以改内容、删除、删掉它之前的全部，或者从这条重新发送。删管家的工具调用时，会连带删掉对应的工具结果，保证格式合法。
- **提示词**：补充要求（追加在内置提示词后面），或者完全自定义（`{记忆}`、`{今天}` 会被自动替换）。可以展开看当前实际发送的完整提示词。
- **参数**：模型、思考强度（low/high/max）、温度、上下文条数，以及编辑权限（可以改数据 / 只读）。改动立即生效，随备份同步。

## 识图

管家输入框左边的"＋"按钮：可以一次选多张照片或截图（最多 8 张；题目、课表、通知、笔记都行），可以附一句话一起发。电脑上可以直接在输入框里粘贴截图。

- 每张图分别交给 `deepseek-flash` 转写成文字和公式，描述按【图片 1】【图片 2】分段存进同一条消息；之后的对话只用文字，不会每轮重复上传。`deepseek-v4-pro` 目前不支持图片，所以识图固定用 flash，聊天用哪个模型不受影响。
- 图片压缩后存在本机，点缩略图看大图。图片不进备份文件，换设备后只剩文字描述。
- 手机上点"＋"没反应，或选完图没有预览：把 App 更新到 v1.29 以上。`设置 → 更新` 只更新页面代码，原生文件选择器要装新 APK（电脑控制台里的"安卓安装包"，覆盖安装不丢数据）。新版做了这些：选图框直接铺在"＋"上；从选择器返回时不再重绘管家面板（否则会把 input 换掉，change 事件就丢了）；去掉多余的 `createChooser` 包装，避免结果回不到 `onActivityResult`；OPPO/vivo 相册返回的 `content://` 先复制到 App 私有缓存，再以 `file://` 交给 WebView。相册文件没有 MIME 类型时会按扩展名认；HEIC 解不开会提示另存为 JPG。

## 长期记忆

管家会把值得长期记住的事实（个人情况、偏好习惯、和你的约定、薄弱知识点）存成记忆，之后每次对话都带上。

- 直接说"记住……""忘掉……""那条改成……"；它也会自己判断要不要记。
- 设置页最上面"管家的长期记忆"可以查看、手动添加、修改、删除。
- 记忆随备份文件和电脑合并同步。删除会留删除标记，另一台设备合并时也跟着删。

## DeepSeek

- 浏览器直接请求 `api.deepseek.com`，默认模型 `deepseek-flash`，可在设置里换成 `deepseek-v4-pro`。
- 讲义生成一次就缓存起来（随备份文件一起导出），以后打开不再花钱。想换一版点"重新生成"。
- 电脑端的 Key 在 `data/config.json` 的 `deepseek_key`。手机通过局域网合并时，如果本机没有 Key，会自动从电脑拿。

## 课表

**课程重要度**：每门课 1–5 星。5★ 必须听、4★ 认真听、3★ 听个大概（留一只耳朵，同时做选择题/背单词）、2★ 基本不听、1★ 随便。4★ 以上课上不推荐考研内容，目标也不排进这节课；3★ 以下课表照常推荐课上做什么。
- 默认：数字信号处理、自动控制原理 4★；机器学习、数字图像处理、操作系统 3★；习概、五史 2★；形势与政策、就业指导 1★。
- 课表页课程名旁边的星星可以点，改整门课，或者"只改今天这一节"。
- 管家也能调：说"周三机器学习要划重点"，它只把那一节调成 5★；说"习概以后都用来背单词"，它把整门课调低。它也会按离考试的远近建议调整，比如期末前把数字信号处理调到 5★。

内置的是本学期课表（第 1 周周一 = 2026-08-31，从教务系统 xls 导出）。换学期：

```
powershell -ExecutionPolicy Bypass -File tools\导出课表.ps1 -Xls "C:\...\学生个人课表.xls" -Week1 2027-03-01
```

会更新 `web/courses.js` 和 `courses.json`。之后重新 build 一份 html 发到手机，或者把 `courses.json` 发到手机，在设置 → 课表 → 导入。节次时间写在 `web/timetable.js` 的 `PERIOD`，吃饭和午睡时段写在 `BLOCKED`。

## 改计划

课时表和阶段在 `web/syllabus.js`。`'分部积分*2'` 表示 2 个课时。新课时只往一章末尾加，不要删除或调换已有条目，否则已打的勾会错位。改完重新运行 `python tools/build.py --with-key`。
